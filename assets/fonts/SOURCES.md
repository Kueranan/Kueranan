# Roboto

Source: [Google Fonts / Roboto](https://github.com/google/fonts/tree/main/ofl/roboto), downloaded on 2026-10-31.

The bundled fonts are static instances of `Roboto[wdth,wght].ttf`, created with fontTools 4.68.0:

- `Roboto-Regular.ttf`: weight 400, width 100.
- `Roboto-Bold.ttf`: weight 700, width 100.

License: SIL Open Font License 1.1; see `OFL.txt`.

Both files were produced with `fontTools.varLib.instancer.instantiateVariableFont`, using `updateFontNames=True`. The generator reads the bundled files directly, so regenerating the artwork does not require a system font installation or fontTools.
